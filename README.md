## Дерева та балансування

У межах завдання реалізовано три незалежні обов’язкові задачі та одне додаткове (опціональне) завдання.

## Завдання 1  
**Пошук найбільшого значення у двійковому дереві пошуку**

Реалізовано функцію, яка знаходить найбільше значення у BST.  
У двійковому дереві пошуку максимальний елемент завжди знаходиться у крайньому правому вузлі.

Файл: `task1_max_value.py`

---

## Завдання 2  
**Пошук найменшого значення у двійковому дереві пошуку**

Реалізовано функцію, яка знаходить найменше значення у BST.  
Мінімальний елемент у BST знаходиться у крайньому лівому вузлі.

Файл: `task2_min_value.py`

---

## Завдання 3  
**Обчислення суми всіх значень у двійковому дереві пошуку**

Реалізовано рекурсивну функцію, яка обчислює суму значень усіх вузлів дерева.

Файл: `task3_sum_values.py`

## Висновки

У ході виконання домашнього завдання:

- продемонстровано рекурсивний підхід до обходу дерев;
- на практиці показано, як ієрархічні структури даних можуть застосовуватися для моделювання реальних систем.
